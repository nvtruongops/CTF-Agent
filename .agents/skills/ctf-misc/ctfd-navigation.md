# CTFd Challenge Page Navigation

Use this guide for an authorized competition hosted on CTFd. Work through the competition website in a browser and follow its published rules.

## Challenge triage

1. Open the challenge page and record its title, category, point value, description, and visible tags.
2. Read the event rules and challenge scope before interacting with any target.
3. Review available hints. Check whether unlocking a hint costs points before opening it.
4. Download only attachments listed on that challenge page. Preserve originals and analyze copies.
5. Record the provided host, port, instance URL, or expiration time exactly as shown.

## During a challenge

- Use the challenge page to refresh dynamic instance details and confirm whether an instance is running.
- Keep probes within the challenge's stated hosts, services, and time limits.
- Follow event rate limits. Stop if the event or organizer pauses the service.
- Keep notes on observations, failed hypotheses, and the source of any flag candidate.

## Flag submission

1. Compare the candidate with the format in the challenge description or event rules.
2. Confirm it came directly from challenge output or a reproducible local artifact.
3. Submit through the challenge page when the user asks for submission or the task includes it.
4. Report the page's response accurately, such as accepted, already solved, or incorrect.

Do not ask for or store an API token for routine navigation. Do not submit guesses or automate submissions.
